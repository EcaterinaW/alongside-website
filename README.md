To use a real hero image:
1. Add your image to the repository, for example `hero.jpg`.
2. In `index.html`, replace the `image-placeholder` div with:
   `<img src="hero.jpg" alt="Parent carrying a child outdoors">`
3. Add this to `styles.css`:
   `.hero-image img { width:100%; height:100%; object-fit:cover; display:block; }`
